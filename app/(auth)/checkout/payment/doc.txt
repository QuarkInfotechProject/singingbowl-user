Web Checkout
Integration
Getpay’s Web Checkout is a fully managed, customizable solution that allows you to conﬁgure payment options, manage orders, and personalize branding, including your company logo. This integration oﬀers a streamlined, ﬂexible approach to online payments, ensuring a smooth and secure experience for both you and your customers.
 Prerequisites
Onboard as a merchant on getpay.
Get the following integration parameter from the corresponding bank.
papInfo,
insKey,
oprKey
Get the checkout library URL (a .js fi le is provided for test development)
Parameters
Title	Description	Datatype	Required
papInfo	This is the Base64 encoded value (Combination of InstitutionId, MID, and TID) this info will be provided by the associated bank.	String	Mandatory
insKey	This is the Unique key to generate hash value for an institution-hosted environment (this fi eld is to be left blank)	String	Non-Mandatory
oprKey	This is the Unique key to generate hash value for Operator-hosted Environment. This information will be provided by the associated bank.	String	Mandatory
clientRequestId	This the Client Unique ID which will be sent by the merchant itself.	String	Non-Mandatory
successUrl	Success page of Client	String	Mandatory
failUrl	Failed page of Client	String	Mandatory
id	This is the getpay Transaction ID	String	 
websiteDomain	Merchant website Base URL	String	Mandatory
Success Page Token	
A unique Base64-encoded string is created by combining the “transaction ID and oprSecret”.

oprSecret: A hash-encoded value generated by the getpay server, used by the client to verify the integrity of communications with the getpay server.
id: The unique transaction identifier.
To validate integrity, generate a unique hash using the (oprKey and transaction ID), then compare this generated hash with oprSecret. If they match, the response from the getpay server is confirmed as authentic. If they do not match, the response may have been tampered with.

String	Mandatory

<script>
const options = {
// user Info is optional. If provided, you can choose to prefill those information in checkout page
userInfo: {
name: "John Doe",
email: "john@gmail.com",
state: "Bagmati",
country: "Nepal",
zipcode: "44600",
city: "Kathmandu",
address: "Chabahil",
},
clientRequestId: "CLIENT123", // You must either provide a value for the field or omit the field entirely.
// insert papInfo, oprKey, insKey provided to you

oprKey: oprKey,
insKey: insKey,
websiteDomain: "https://www.store.com", // your website url
price: 55.12, // total amount -- default NPR
businessName: "OneStop Shopping - Rediscover a great shopping tradition", // your businessName with slogan to display in checkout page
imageUrl:
"https://store.com/image.png", // company logo to display in checkout page
currency: "NPR",
// provided attributes with value true will autofill in checkout page
prefill: {
name: true,
email: true,
state: true,
city: true,
address: true,
zipcode: true,
country: true
},
// provided attributes with value true will be disabled in checkout page. Note that you must only disable fields which are prefilled
disableFields: {
address: true,
state: true, // address and state fields will be disabled in checkout page
},
// redirection callback url when payment is either success or fail
callbackUrl: {
successUrl: 'https://www.store.com/success.html',
failUrl: 'https://www.store.com/fail.html',
},
// brand theme color to display in checkout page
themeColor: "#5662FF",
// accept html with inline css to display UI in checkout page
orderInformationUI: `<div style="font-family:Arial;"><h3>Order Information</h3><div class="item" style="
margin-bottom: 20px;">
<div class="item">
<img style=" max-width: 50px;
margin-right: 10px;" src="https://store.com/image.png" alt="image">
<p>Cup Set</p>
<span>Rs 450</span>
</div></div>`,
onSuccess: (options) => {
//you can receive options if needed
// redirect to payment checkout page on success
window.location.href = "./payment.html"
},
onError: (error) => {
// if error occured during checkout
console.log(error);
},
};
document.getElementById('checkout-btn').onclick = function (e) {
options.baseUrl = ‘http://localhost:8080’;
const getpay = new GetPay(options);

}
</script>
</body>
</html>

METHOD: POST API: {baseURL}/v1/secure-merchant/transactions/merchant-status
REQUEST BODY(Json Type):
{
"id":"id fetch from tokenInfo",
"papInfo":"Already Provided Pap Info"
}
